# GiftList & WishList Maker - Official Companion Website

This is the standalone companion website for **GiftList & WishList Maker** for Android, developed by **MZ Developers** (`mzdevelopers001@gmail.com`).

The site is built with pure, zero-dependency HTML5, CSS3, and JavaScript, configured for instant deployment on [Vercel](https://vercel.com). It is strictly compliant with the operating policies of **Amazon Associates** and the **eBay Partner Network (EPN)**.

## How to Deploy to Vercel

### Option 1: Via GitHub (Recommended)

1. Create a new public or private repository on your GitHub account (e.g. `giftlist-wishlist-maker-web`).
2. Run these commands inside this folder:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of GiftList & WishList Maker companion website"
   git branch -M main
   git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/giftlist-wishlist-maker-web.git
   git push -u origin main
   ```
3. Go to [vercel.com](https://vercel.com), click **"Add New..."** &rarr; **"Project"**.
4. Import your `giftlist-wishlist-maker-web` repository.
5. In **Framework Preset**, select **"Other"** (or leave default).
6. Click **Deploy**. Vercel will build and assign you a free live URL (such as `https://giftlist-wishlist-maker.vercel.app`).

---

### Option 2: Deploy Directly via Vercel Dashboard Drag & Drop

You can also deploy directly by dragging and dropping this folder into the Vercel dashboard:
- Go to [vercel.com/new](https://vercel.com/new) and choose the manual upload option.

## Submitting to Amazon Associates & eBay EPN

Once your Vercel URL is live:
1. **Amazon Associates Central**:
   - In the **Websites and Mobile Apps List** step, paste your live Vercel URL under **Website List** (e.g., `https://giftlist-wishlist-maker.vercel.app`).
   - Describe your website: *"A mobile app companion site and gift registry planner that helps users organize event budgets, track gift ideas, and compare products across Amazon and other retailers."*
   - Under topics, select: *Home/Family/Pets*, *Shopping*, or *Tech*.
2. **eBay Partner Network (EPN)**:
   - Paste the Vercel URL as your primary Promotional Property.
   - Business Model: *Shopping Comparison / Loyalty & Registry Tool*.
